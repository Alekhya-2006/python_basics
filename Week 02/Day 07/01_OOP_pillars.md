# OOP Pillars

## Encapsulation
- Wrapping data and methods into a single unit (class)
- Data hiding

### Access Modifiers
- Public → accessible everywhere
- Protected (_var) → intended for class/subclass use
- Private (__var) → intended for class-only use (name mangling)

Note:
Python has no strict private/protected access control.

---

## Inheritance
- Reusing attributes and methods from parent classes
- Helps code reuse and extension

### Types
- Single Inheritance
- Multi-Level Inheritance
- Multiple Inheritance

---

## Abstraction
- Hides implementation details and exposes essential features
- Uses abstract classes (`abc` module)
- Abstract classes act as blueprints for child classes

---

## Polymorphism
- Same method name behaves differently for different objects

Examples:
- Method Overriding
- Duck Typing
